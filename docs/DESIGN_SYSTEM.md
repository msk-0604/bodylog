# BODYLOG デザインシステム

最終更新: 2026-10-24
実装: [`src/theme/tokens.ts`](../src/theme/tokens.ts)（唯一の定義元）・[`src/components/ui`](../src/components/ui)

## 1. 原則

1. **速さ**: 主要操作は親指の届く範囲・最小タップ数。待たせない（楽観的更新、スケルトン）。
2. **静けさ**: 白基調・落ち着いたグリーン1色のアクセント。装飾より余白と文字組みで階層を作る。
3. **責めない**: 目標超過は「目標を超えています」「+300 kcal」と事実のみ。赤色や警告アイコンは使わず、注意色（warning）で控えめに示す。
4. **誰でも読める**: Dynamic Type・VoiceOver/TalkBack・ダークモード・アニメーション軽減に対応。

## 3. タイポグラフィ

システムフォント（iOS: SF Pro / ヒラギノ、Android: Roboto / Noto Sans CJK）。和文の可読性のため行間は広め。

| variant            | size / line      | weight | 用途               |
| ------------------ | ---------------- | ------ | ------------------ |
| largeTitle         | 32 / 40          | 700    | 画面タイトル       |
| title1             | 26 / 34          | 700    | 大きな数値（体重） |
| title2             | 21 / 28          | 700    | カード見出し       |
| title3             | 19 / 26          | 600    | セクション見出し   |
| headline           | 17 / 24          | 600    | ボタン・強調       |
| body               | 17 / 26          | 400    | 本文               |
| callout / subhead  | 16 / 23, 15 / 21 | 400    | 補足               |
| footnote / caption | 13 / 19, 12 / 16 | 400    | 注記               |
| display            | 40 / 46          | 700    | カロリーリング中央 |

- 数値は `tabular` 指定（等幅数字）で変化時に揺れない。
- 大きな数値は `maxFontSizeMultiplier` で上限を設け、Dynamic Type 最大でもレイアウトを崩さない。

## 4. スペーシング・角丸・タップ領域

- spacing: 2 / 4 / 8 / 12 / 16 / 20 / 24 / 32（画面左右 16）
- radius: 8 / 12 / 16 / 22 / pill
- 最小タップ領域: **48pt**（Apple 44pt / Material 48dp の大きい方）
- タブバー: 高さ 56 + 下部セーフエリア（和文ラベルが欠けないよう既定49から拡張）

## 5. モーション

- 押下: 0.97倍に縮小（160ms）。OSの「視差効果を減らす／アニメーション削除」が有効なら不透明度変化のみ。
- 進捗（リング・バー）: 600ms ease-out。アニメーション軽減時は即時表示。
- スケルトン: 800ms の穏やかな明滅。軽減時は静止。
- タブ切替: フェード。モーダル: OS標準。
- 過剰な演出（バウンス・パーティクル等）は使わない。

## 6. ハプティクス

| 場面                     | 種類      |
| ------------------------ | --------- |
| ボタン・タブ・行のタップ | selection |
| 保存完了                 | success   |
| 入力エラー・削除確認     | warning   |

失敗（非対応端末）は無視する。

## 9. 文言ガイド

- です・ます調。短く、具体的に。
- 否定・叱責・不安を煽る表現を避ける（例: ✕「食べ過ぎです」→ ○「目標を超えています」）。
- 推定値は必ず「推定」と書く。医療的な断定をしない。
- 未実装機能を実装済みのように見せない（「準備中」と表示）。
